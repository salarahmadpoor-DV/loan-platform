# API Endpoints - MVP

این سند فهرست دقیق endpointهای پیشنهاد شده برای نسخه MVP پلتفرم معرفی و Matching خدمات (شامل Plumbing و Loan به عنوان سرویس‌ها) را ارائه می‌دهد.

فایل مرجع ایجاد شده توسط Copilot CLI runtime در VS Code.

## 1) احراز هویت / کاربر

- POST /api/auth/send-otp
  - ارسال کد OTP به شماره موبایل
  - Body: { "mobile": "0912..." }
  - Response: 202 Accepted یا 200 { "requestId": "..." }

- POST /api/auth/verify-otp
  - تأیید OTP و ایجاد/ورود کاربر
  - Body: { "mobile": "0912...", "otp": "123456", "requestId": "..." }
  - Response: 200 { "accessToken": "...", "refreshToken": "...", "user": { id, mobile, roles[] } }

- GET /api/users/me
  - دریافت پروفایل کاربر
  - Authorization: Bearer

- PUT /api/users/me
  - ویرایش/تکمیل پروفایل
  - Authorization: Bearer

## 2) سرویس‌ها و دسته‌بندی‌ها

- GET /api/service-categories
  - لیست دسته‌بندی‌ها
  - Query: ?includeServices=true

- GET /api/services
  - لیست سرویس‌ها (فیلتر با category)
  - Query: ?categoryId=&q=&page=&pageSize=

- GET /api/services/{serviceId}
  - جزئیات سرویس به همراه سوالات (ServiceQuestion)

## 3) ثبت درخواست (ServiceRequest)

- POST /api/requests
  - ایجاد درخواست همراه با پاسخ سوالات
  - Authorization: Bearer
  - Body:
    {
      "serviceId": "...",
      "title": "...",
      "description": "...",
      "location": { "lat": ..., "lng": ..., "address": "..." },
      "preferredTime": { "from": "...", "to": "..." },
      "answers": [ { "questionId": "...", "optionId": null, "text": "..." } ],
      "attachments": [ "url-or-temp-id" ]
    }
  - Response: 201 { requestId, status: "Created", matchingStatus: "Pending" }

- GET /api/requests/{requestId}
  - مشاهده جزئیات درخواست

- GET /api/users/{userId}/requests
  - لیست درخواست‌های یک کاربر

## 4) Matching

- POST /api/requests/{requestId}/match
  - اجرای Matching (خودکار یا دستی)
  - Body (اختیاری): { "method": "basic" }
  - Response: 200 { matchedProviders: [...], matchedBusinesses: [...] }

- GET /api/requests/{requestId}/matches
  - مشاهده candidate های matched

## 5) Introduction (معرفی)

- POST /api/introductions
  - ثبت معرفی برای Request به Provider یا Business
  - Authorization: Bearer (system / authorized roles)
  - Body: { "requestId": "...", "targetType": "Provider|Business", "targetId": "...", "source": "Matching|Manual" }

- GET /api/requests/{requestId}/introductions

- PUT /api/introductions/{introductionId}/assign
  - اختصاص دادن provider (برای معرفی به Business)
  - Authorization: Bearer (Business owner)
  - Body: { "providerId": "..." }

- PUT /api/introductions/{introductionId}/confirm
  - Provider/Business تأیید یا رد معرفی
  - Body: { "status": "Accepted|Rejected" }

## 6) Review و Rating

- POST /api/introductions/{introductionId}/reviews
  - ثبت review مرتبط با introduction
  - Authorization: Bearer (صاحب request)
  - Body: { "targetType": "Provider|Business", "targetId": "...", "rating": 1-5, "comment": "..." }

- GET /api/providers/{providerId}/reviews
- GET /api/businesses/{businessId}/reviews

## 7) Provider / Business management (حداقل برای MVP)

- POST /api/providers
  - ایجاد Provider (در MVP ممکن است از طریق seed یا invitation انجام شود)

- GET /api/providers/{providerId}

- GET /api/businesses
- POST /api/businesses
- POST /api/businesses/{businessId}/invite-provider
- PUT /api/business-providers/{businessProviderId}/accept

## 8) جستجو و فیلترها

- GET /api/providers
  - Query: ?serviceId=&lat=&lng=&radiusKm=&sort=distance|rating|score&page=&pageSize=

## 9) کمکی

- GET /api/health
- GET /api/metrics (اختیاری، admin)

---

### ملاحظات پیاده‌سازی

- احراز هویت: JWT با نقش‌ها (Customer, Provider, BusinessOwner, Admin)
- Authorization: قوانین مالکیت و نقش‌ها در هر endpoint
- Validation: استفاده از FluentValidation برای DTOها
- Reviews فقط در ارتباط با Introduction/Request ثبت شوند
- Pagination و rate limiting برای لیست‌ها
- Matching اولیه: distance + availability + rating fallback

### پیشنهادهای بعدی

- ایجاد scaffold کنترلرها و DTOها برای endpointهای بالا
- طراحی دقیق DTOها و FluentValidation rules
- ایجاد migrationهای EF Core برای مدل‌های جدید (Service, ServiceQuestion, ServiceRequest, Introduction, Review)
